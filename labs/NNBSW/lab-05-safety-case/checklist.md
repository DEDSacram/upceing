# Safety-case review checklist

1. Is the top goal precise (system + environment + acceptance criterion)?
2. Does the strategy cover ALL hazards from the hazard log (no orphans)?
3. Does every Goal bottom out in ≥1 Solution (test/proof/analysis)?
4. Is each Solution versioned and retrievable (report id + date)?
5. Are Assumptions explicit and each backed by a validation argument?
6. Is counter-evidence (failures, open defects) addressed, not hidden?
7. Would an independent assessor reach the same conclusion from this file?

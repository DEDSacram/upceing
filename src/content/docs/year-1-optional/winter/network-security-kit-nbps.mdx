## Week 1: Introduction to Security Threats

This week introduces the landscape of security threats, threat actors, attack surfaces, and the fundamental goals of security (CIA triad).

### Key Concepts

- **Security Threats** – Malware, phishing, DDoS, insider threats, APTs (Advanced Persistent Threats).
- **Attack Surface** – The sum of all points where an attacker can try to enter or extract data.
- **CIA Triad** – Confidentiality, Integrity, Availability.
- **Risk Management** – Identification, assessment, and mitigation of risks.

### Threat Modeling Example (STRIDE)

- **S**poofing – pretending to be someone else.
- **T**ampering – modifying data.
- **R**epudiation – denying an action.
- **I**nformation disclosure – leaking data.
- **D**enial of service – making a service unavailable.
- **E**levation of privilege – gaining higher access.

## Week 2: Network Security Fundamentals

This week covers the core concepts of network security: authentication, authorization, accounting (AAA), defence in depth, and secure design principles.

### Key Concepts

- **Defence in Depth** – Layered security: physical, network, host, application, data.
- **AAA** – Authentication (who you are), Authorization (what you can do), Accounting (what you did).
- **Security Zones** – Inside, DMZ, outside; trust levels.
- **Network Segmentation** – VLANs, subnets, firewalls to contain breaches.

### Example: Access Control List (ACL) on Cisco

```
! Deny telnet from outside, allow SSH only from management subnet
access-list 101 deny tcp any any eq 23
access-list 101 permit tcp 192.168.10.0 0.0.0.255 any eq 22
```

## Week 3: Attacks on Network Foundations

This week examines common network‑layer attacks and their countermeasures.

### Key Concepts

- **ARP Spoofing** – Attacker sends fake ARP replies to associate their MAC with a legitimate IP.
- **IP Spoofing** – Forging source IP addresses.
- **Sniffing** – Capturing network traffic (e.g., using Wireshark) to steal credentials or data.
- **DoS/DDoS** – Overwhelming a target with traffic to disrupt services.
- **Mitigation** – Dynamic ARP inspection, IPsec, encryption (TLS), rate limiting, and intrusion detection.

## Week 4: Response to Attacks

Preparation, detection, containment, eradication, and recovery – the incident response lifecycle.

### Key Concepts

- **Incident Response Plan** – Documented steps to follow when a security incident occurs.
- **Phases** – Preparation, Identification, Containment, Eradication, Recovery, Lessons Learned.
- **Forensics** – Collecting and analyzing evidence (disk, memory, network logs) while maintaining chain of custody.
- **SIEM** – Security Information and Event Management (e.g., Splunk, ELK) for centralized logging and alerting.

### Creating an Incident Response Checklist

```python
def incident_response_checklist():
    return {
        'Preparation': 'Train team, update tools, define roles',
        'Identification': 'Monitor alerts, confirm incident',
        'Containment': 'Isolate affected systems, block malicious IPs',
        'Eradication': 'Remove malware, patch vulnerabilities',
        'Recovery': 'Restore from clean backups, verify integrity',
        'Lessons Learned': 'Conduct post‑mortem, update policies'
    }
```

## Week 5: Wireless Network Security

Wireless networks are inherently less secure. This week covers Wi‑Fi security protocols, common attacks, and best practices.

### Key Concepts

- **Wi‑Fi Security Protocols** – WEP (broken), WPA, WPA2, WPA3.
- **Attacks** – Rogue AP, Evil Twin, KRACK, deauthentication attacks.
- **WPA3 Improvements** – SAE (Simultaneous Authentication of Equals), stronger encryption.
- **802.1X** – Port‑based authentication for enterprise Wi‑Fi (RADIUS).

### Auditing a Wi‑Fi Network (Using `airodump-ng`)

```bash
# Enable monitor mode
airmon-ng start wlan0
# Scan for networks
airodump-ng wlan0mon
# Capture handshake (for WPA)
airodump-ng -c 6 --bssid AA:BB:CC:DD:EE:FF -w capture wlan0mon
# Deauth attack to force reauthentication
aireplay-ng -0 2 -a AA:BB:CC:DD:EE:FF -c client_mac wlan0mon
```

## Week 6: Network Infrastructure Security

Securing routers, switches, and other infrastructure devices is critical to prevent attacks on the network backbone.

### Key Concepts

- **Router Security** – Disable unused services, use SSH instead of Telnet, enable logging, configure ACLs.
- **Switch Security** – Port security (MAC limiting), VLAN trunking hardening, STP protection (BPDU guard).
- **Management Plane** – Secure SNMP (v3), out‑of‑band management, role‑based access.
- **NGFW** – Next‑Generation Firewalls with application awareness, IPS, and SSL inspection.

### Example: Basic Router Hardening (Cisco IOS)

```
! Secure SSH
ip domain-name example.com
crypto key generate rsa modulus 2048
username admin secret StrongPass123
line vty 0 4
 transport input ssh
 login local
 exit
! Disable unused ports
interface gi0/0
 shutdown
! Logging
logging 192.168.1.100
service timestamps log datetime msec
```

## Week 7: Windows OS Security

This week focuses on securing Windows 11 Pro and forms the technical basis for the semester project – building a security auditing application.

### Key Concepts

- **Windows Security Components** – Windows Defender Antivirus, Windows Update, User Account Control (UAC), BitLocker, TPM.
- **Security Configuration** – Local Group Policy, Security Compliance Toolkit.
- **PowerShell for Auditing** – Using cmdlets to query security settings.

### PowerShell Script for Security Checks

```powershell
# Check Windows Defender status
Get-MpComputerStatus | Select-Object AntivirusEnabled, RealTimeProtectionEnabled, AntivirusSignatureVersion

# Check Windows Update status
Get-WUHistory | Select-Object -Last 5

# Check UAC settings
Get-ItemProperty "HKLM:\SOFTWARE\Microsoft\Windows\CurrentVersion\Policies\System" | Select-Object EnableLUA, ConsentPromptBehaviorAdmin

# List administrators
Get-LocalGroupMember -Group "Administrators"

# Check BitLocker status
Get-BitLockerVolume | Select-Object MountPoint, ProtectionStatus

# Check open ports (listening)
netstat -an | findstr LISTENING
```

## Week 8: Linux OS Security

Linux is widely used in servers and IoT; securing it is vital. This week covers hardening, auditing, and monitoring.

### Key Concepts

- **System Hardening** – Disable unused services, configure firewall (nftables/iptables), enforce strong passwords, enable SELinux/AppArmor.
- **Secure SSH** – Disable root login, use key‑based authentication, change default port (optional).
- **Auditing Tools** – `lynis`, `chkrootkit`, `rkhunter`.
- **File Integrity** – `tripwire`, `aide` to detect changes.

### Hardening SSH

```bash
# /etc/ssh/sshd_config
PermitRootLogin no
PubkeyAuthentication yes
PasswordAuthentication no
AllowUsers user1 user2
Port 2222  # optional
```

## Week 9: Endpoint Security Concepts

Endpoint security goes beyond antivirus. This week covers EDR, DLP, and device control.

### Key Concepts

- **Antivirus vs. EDR** – Traditional AV uses signatures; EDR provides behavioral monitoring, threat hunting, and response.
- **Endpoint Detection and Response (EDR)** – Collects endpoint telemetry and enables investigation.
- **Data Loss Prevention (DLP)** – Prevents sensitive data from leaving the organization.
- **Application Control** – Whitelisting/blacklisting applications (e.g., Windows AppLocker, Linux seccomp).

### Example: Open‑Source EDR – Wazuh Integration

```bash
# Install Wazuh agent on endpoint
wget https://packages.wazuh.com/4.x/apt/pool/main/w/wazuh-agent/wazuh-agent_4.7.0-1_amd64.deb
dpkg -i wazuh-agent_4.7.0-1_amd64.deb
# Configure manager address
echo "MANAGER_IP=10.0.0.10" >> /var/ossec/etc/ossec.conf
systemctl start wazuh-agent
```

## Week 11: Firewalls and VPN Technologies

Firewalls and VPNs are essential for network security. This week covers types, configurations, and best practices.

### Key Concepts

- **Firewall Types** – Packet‑filtering, stateful, proxy, NGFW (with IPS/IDS).
- **VPN** – Site‑to‑site and remote access; IPsec and SSL/TLS VPNs.
- **IPsec** – AH and ESP, IKE, tunnel vs. transport mode.
- **VPN Deployment** – Gateway configuration, split‑tunneling, and security considerations.

### Configuring IPsec (strongSwan)

```
# ipsec.conf
conn site-to-site
    left=192.168.1.1
    leftsubnet=192.168.1.0/24
    leftid=@siteA
    right=203.0.113.2
    rightsubnet=10.0.0.0/24
    rightid=@siteB
    ike=aes256-sha256-modp2048
    esp=aes256-sha256
    keyingtries=%forever
    auto=start
```

## Week 12: Secure Access and Authentication

Authentication is the gateway to resources. This week covers 802.1X, RADIUS, MFA, and PKI.

### Key Concepts

- **802.1X** – Port‑based network access control, uses EAP.
- **RADIUS** – Centralized authentication, authorization, and accounting.
- **MFA** – Something you know, have, are – e.g., OTP, biometrics.
- **PKI** – Public Key Infrastructure for certificates (e.g., for 802.1X and HTTPS).

### Example: FreeRADIUS Configuration Snippet

## Code Review Guide

When reviewing project code, focus on:

### Functionality
- Does the tool correctly detect the status of each security setting?
- Are the outputs accurate and up‑to‑date?

### Code Quality
- Is the code well‑structured (functions, modules)?
- Are error conditions handled gracefully (e.g., permissions, missing registry keys)?

### Security of the Tool Itself
- Does the tool run with the least privileges necessary?
- Is the GUI safe from injection (e.g., no executing user input)?

### Example Review Note

<div class="review-note">

<strong>🔍 Code Review Example:</strong>

```python
def check_defender():
    try:
        status = subprocess.check_output(["powershell", "Get-MpComputerStatus"]).decode()
        if "True" in status:
            return "Enabled"

### Common Network Attacks and Mitigations

| Attack | Mitigation |
| :--- | :--- |
| ARP Spoofing | Dynamic ARP Inspection, static ARP entries |
| IP Spoofing | Ingress/Egress filtering, RPF (Reverse Path Forwarding) |

| Man‑in‑the‑Middle | TLS, IPsec, SSH, strong authentication |
| Password Cracking | Strong passwords, MFA, account lockout policies |

### Windows Security Checks – Useful PowerShell Cmdlets

| Check | Cmdlet / Method |
| :--- | :--- |
| Antivirus status | `Get-MpComputerStatus` |
| Windows Update history | `Get-WUHistory` |
| UAC settings | Registry: `HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\Policies\System` |
| Administrators | `Get-LocalGroupMember -Group "Administrators"` |
| BitLocker | `Get-BitLockerVolume` |
| Open ports (listening) | `Get-NetTCPConnection -State Listen` |
| SMBv1 enabled | `Get-WindowsOptionalFeature -Online -FeatureName SMB1Protocol` |

### Linux Hardening Quick Tips

- **Firewall** – `sudo ufw enable` or `nftables`.
- **SSH** – Disable root login, use keys.
- **SELinux** – Enable and set to enforcing.
- **Audit** – Run `lynis audit system`.
- **Updates** – `apt update && apt upgrade` or `dnf update`.

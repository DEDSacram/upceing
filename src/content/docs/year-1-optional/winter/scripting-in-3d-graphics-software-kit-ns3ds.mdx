## Week 1: The Basics of MEL Commands

MEL (Maya Embedded Language) is the scripting language built into Autodesk Maya. This week introduces the basics: how to run MEL commands, create objects, and understand the Script Editor.

### Key Concepts

- **Script Editor** – The primary tool for writing and testing MEL scripts. Can be opened via `Window > General Editors > Script Editor`.
- **Command Line** – Execute single commands directly in the Script Editor or the command line.
- **Basic Commands** – `polySphere`, `polyCube`, `move`, `rotate`, `scale`.
- **MEL vs. Python** – Maya supports both MEL and Python; this course focuses on MEL.

### Your First MEL Script

```mel
// Create a sphere
polySphere -r 2 -sx 20 -sy 20 -name "mySphere";
// Move it up
move 3 5 0 "mySphere";
// Print a message to the Script Editor
print "Sphere created and moved!\n";
```

## Week 2: Problem Solving with MEL Scripting

This week focuses on using MEL to solve practical problems, such as creating a row of objects or performing batch operations.

### Key Concepts

- **Scripting Workflow** – Identify the problem, break it down, write and test the script.
- **Comments** – Use `//` for single‑line comments and `/* ... */` for multi‑line comments.
- **Echoing Commands** – Enable "Echo All Commands" in the Script Editor to see what MEL commands Maya generates when you use the UI.

### Example: Creating a Row of Cubes

```mel
// Create a row of 5 cubes spaced 3 units apart
for ($i = 0; $i < 5; $i++) {
    string $cubeName = "cube_" + $i;
    polyCube -name $cubeName;
    move ($i * 3) 0 0 $cubeName;
}
```

## Week 3: Variables and Data Types

MEL supports several data types for storing and manipulating data. This week covers variables, data types, and type conversion.

### Key Concepts

- **Variable Declaration** – Use the `$` prefix for variables.
- **Data Types** – `int`, `float`, `string`, `vector` (Maya-specific).
- **Type Conversion** – `int()`, `float()`, `string()`.
- **Arrays** – `$myArray[0]`, `$myArray[1]`, etc. (MEL arrays are dynamic).

### Working with Variables

```mel
// Integer and float
int $count = 10;
float $radius = 5.5;

// String
string $objectName = "myObject";

// Vector (Maya's vector type)
vector $position = <<3.0, 5.0, 2.0>>;
float $x = $position.x;
float $y = $position.y;
float $z = $position.z;

// Array
string $objects[];
$objects[0] = "cube1";
$objects[1] = "sphere1";
$objects[2] = "cylinder1";

// Loop through array
for ($i = 0; $i < size($objects); $i++) {
    print($objects[$i] + "\n");
}
```

## Week 4: Using MEL Commands

MEL has hundreds of commands. This week covers the most frequently used commands for object creation, transformation, and selection.

### Key Concepts

- **Object Creation** – `polySphere`, `polyCube`, `polyCylinder`, `polyCone`.
- **Transformation** – `move`, `rotate`, `scale`, `setAttr`.
- **Selection** – `select`, `ls` (list selected objects), `pick`.
- **Naming Convention** – Commands often have flags (e.g., `-r` for radius).
- **Return Values** – Many commands return the name of the created object.

### Common Commands and Flags

```mel
// Create a sphere with specific attributes
polySphere -r 3 -sx 30 -sy 30 -name "bigSphere";
// Returns: bigSphere

// Move with absolute and relative values
move 2 4 1 "bigSphere";  // Absolute
move -r 1 0 0 "bigSphere"; // Relative

// Get and set attributes
float $currentScaleX = getAttr("bigSphere.scaleX");
setAttr "bigSphere.scaleX" 2.0;

// Select an object and get the selection list
select "bigSphere";
string $selected[] = `ls -sl`;  // Backticks execute command
```

## Week 5: Manipulating Nodes in MEL

Maya organizes scenes as a hierarchy of nodes. This week covers how to select, group, parent, and manipulate nodes.

### Key Concepts

- **Nodes** – Every object in Maya is a node (transform node, shape node, etc.).
- **Parenting** – `parent` command; `listRelatives` to list parent/children.
- **Grouping** – `group` command; creates a new transform parent.
- **Node Selection** – Use `ls -type` to list nodes by type.
- **Naming** – Nodes can be renamed with `rename`.

### Node Manipulation Commands

```mel
// Create and rename a sphere
string $sphere = `polySphere -r 2`;
rename $sphere "myBeautifulSphere";

// Group objects
select "cube1" "sphere1" "cylinder1";
string $group = `group`;

// Parent a sphere under a cube
parent "sphere1" "cube1";

// List children of a node
string $children[] = `listRelatives -children "cube1"`;

// Find all transform nodes
string $allTransforms[] = `ls -type "transform"`;

// Delete a node
delete "sphere1";
```

## Week 6: Controlling the Flow of Execution

MEL supports standard control structures for decision making and repetition.

### Key Concepts

- **Conditionals** – `if`, `else if`, `else`.
- **Loops** – `for`, `while`, `do-while`.
- **Break and Continue** – `break`, `continue`.
- **Switch Statement** – `switch` (less common but useful for UI handling).

### Flow Control Examples

```mel
// If statement
int $count = 5;
if ($count > 10) {
    print "Count is greater than 10\n";
} else if ($count == 5) {
    print "Count is exactly 5\n";
} else {
    print "Count is less than 5\n";
}

// For loop
for ($i = 0; $i < 10; $i++) {
    if ($i == 5) {
        continue;  // Skip iteration
    }
    print("i = " + $i + "\n");
}

// While loop
int $j = 0;
while ($j < 5) {
    print("j = " + $j + "\n");
    $j++;
}

// Switch
string $choice = "sphere";
switch ($choice) {
    case "sphere":
        polySphere;
        break;
    case "cube":
        polyCube;
        break;
    default:
        print "Unknown object type\n";
}
```

## Week 7: Procedures and Functions

Procedures (functions) allow you to encapsulate reusable code. This week covers creating and using `proc` in MEL.

### Key Concepts

- **Procedure Definition** – `proc returnType functionName(parameters) { ... }`.
- **Return Values** – Use `return` to return a value.
- **Scope** – Variables inside a procedure are local by default.
- **Global vs. Local** – Use `global` to make variables accessible outside the procedure.
- **Default Parameters** – MEL doesn't support default parameters directly; use overloading or conditional checks.

### Creating and Using Procedures

```mel
// Simple procedure with no parameters
proc createScene() {
    polySphere -r 1;
    polyCube -w 2 -h 2 -d 2;
    print "Scene created!\n";
}

// Procedure with parameters
proc string createObject(string $type, float $size) {
    string $result;
    switch ($type) {
        case "sphere":
            $result = `polySphere -r $size`;
            break;
        case "cube":
            $result = `polyCube -w $size -h $size -d $size`;
            break;
        default:
            print "Unknown type\n";
            return "";
    }
    return $result;
}

// Procedure with return value
proc float calculateVolume(float $radius) {
    return (4.0 / 3.0) * 3.14159 * pow($radius, 3);
}

// Call the procedures
createScene;
```java
string $obj = createObject("sphere", 2.0);
```
float $vol = calculateVolume(2.0);
print("Volume: " + $vol + "\n");
```

## Week 8: Designing MEL User Interfaces

MEL provides commands for creating custom user interfaces. This week covers the basics of UI layout and controls.

### Key Concepts

- **UI Hierarchy** – `window` → layouts (`columnLayout`, `rowLayout`) → controls (`button`, `text`, `textField`).
- **Window Creation** – Use `window` command to create a window.
- **Layouts** – Organize UI elements.
- **Controls** – Buttons, text fields, sliders, option menus, etc.
- **UI Commands** – Commands like `button` have a `-command` flag to specify what happens when clicked.

### A Basic UI Window

```mel
proc createUI() {
    window -title "My First UI" -widthHeight 300 200;
    columnLayout -adj true;
    
    text -label "Welcome to my tool!" -font "boldLabelFont";
    separator -height 10;
    
    button -label "Create Sphere" -command "polySphere -r 2";
    button -label "Create Cube" -command "polyCube -w 3 -h 3 -d 3";
    button -label "Close" -command "deleteUI -window $myWindow";
    
    showWindow;
}

// Call the UI creation procedure
createUI;
```

## Week 9: Simple MEL User Interfaces

This week dives deeper into building practical UIs, including how to handle user input and update the scene dynamically.

### Key Concepts

- **Getting User Input** – Use `textFieldGrp`, `floatSliderGrp`, `intSliderGrp`.
- **Command Strings** – Build command strings dynamically using `+` concatenation.
- **Global Variables** – Use `global` to share data between UI elements.
- **Refresh UI** – Use `uiResize` or `refresh` when updating the UI.

### UI with Input Controls

```mel
global string $gObjectName = "myObject";
global float $gRadius = 1.0;

proc createToolUI() {
    window -title "Object Creator" -widthHeight 350 250;
    columnLayout -adj true;
    
    text -label "Object Creation Tool" -font "boldLabelFont";
    separator -height 10;
    
    text -label "Object Name:";
    textFieldGrp -text $gObjectName -changeCommand "gObjectName = `textFieldGrp -query -text`";
    
    text -label "Sphere Radius:";
    floatSliderGrp -field true -min 0.1 -max 10 -value $gRadius 
                   -changeCommand "gRadius = `floatSliderGrp -query -value`";
    
    separator -height 10;
    
    button -label "Create Sphere" -command createSphereUI;
    button -label "Close" -command "deleteUI -window $myWindow";
    
    showWindow;
}

proc createSphereUI() {
    string $cmd = "polySphere -r " + $gRadius + " -name " + $gObjectName;
    eval($cmd);
    print("Created: " + $gObjectName + "\n");
}
```

## Week 10: Custom Dialog Boxes

Dialog boxes are used to get input from the user or display information. This week covers `promptDialog`, `fileDialog`, and `confirmDialog`.

### Key Concepts

- **promptDialog** – Get text input from the user.
- **fileDialog** – Browse for files or directories.
- **confirmDialog** – Show a yes/no or ok/cancel dialog.
- **Dialog Results** – Check the result and retrieve input.

### Working with Dialogs

```mel
// Prompt dialog
proc promptForNumber() {
    string $result = `promptDialog
        -title "Input"
        -message "Enter a number:"
        -text "5"
        -button "OK" -button "Cancel"`;
    
    if ($result == "OK") {
        string $value = `promptDialog -query -text`;
        float $num = float($value);
        print("You entered: " + $num + "\n");
    }
}

// File dialog - select a file
proc browseFile() {
    string $file = `fileDialog
        -fileMode 1  // 1 = open file, 0 = save file
        -title "Select a file"`;
    if ($file != "") {
        print("Selected: " + $file + "\n");
    }
}

// Confirm dialog
proc confirmDelete() {
    string $result = `confirmDialog
        -title "Confirm Delete"
        -message "Delete selected objects?"
        -button "Yes" -button "No"
        -defaultButton "No"`;
    
    if ($result == "Yes") {
        string $selected[] = `ls -sl`;
        delete $selected;
        print("Deleted " + size($selected) + " objects\n");
    }
}
```

## Week 12: Using Expressions

Maya expressions allow you to control animation attributes mathematically. This week covers the basics of expression syntax and application.

### Key Concepts

- **Expression** – A MEL statement that runs every frame to set an attribute.
- **Creation** – Use `expression` command or the Expression Editor (`Window > Animation Editors > Expression Editor`).
- **Variables** – `frame` is a special variable that gives the current frame number.
- **Time** – `time` variable gives the current time in seconds.
- **Syntax** – Expressions are similar to MEL but with restrictions.

### Animation Expressions

```mel
// Simple oscillation expression (bouncing ball)
// On the translateY attribute of a sphere
sphere.translateY = 5 * sin(time * 2);

// Advanced: bounce with damping
float $bounce = 5;
float $damping = 0.98;
float $velocity = -10;
// This is simplified; full physics requires more complex setup

// Expression using frame
// Scale oscillates with frame
polySphere.scaleX = 1 + 0.5 * sin(frame * 0.1);
polySphere.scaleY = 1 + 0.5 * sin(frame * 0.1 + 2);
polySphere.scaleZ = 1 + 0.5 * sin(frame * 0.1 + 4);

// Conditional expression (flashing light)
if (frame % 10 < 5) {
    spotlight.intensity = 1;
} else {
    spotlight.intensity = 0;
}
```

## Week 13: Controlling Particles with Expressions

Particle systems are a core feature of Maya for creating effects like fire, smoke, and explosions. This week covers using expressions to control particle behavior.

### Key Concepts

- **Particle Systems** – Create particles with `particle` command or the Dynamics menu.
- **Particle Attributes** – `position`, `velocity`, `lifespan`, `color`, `size`, etc.
- **Per‑Particle Expressions** – Expressions that run per particle, using `particleShape.attribute` syntax.
- **Creation Expressions** – Run once when a particle is created.
- **Runtime Expressions** – Run every frame for each particle.

### Particle Control with Expressions

```mel
// Create a basic particle system
particle -position 0 0 0 -count 100 -name "fireParticles";

// Creation expression - set initial random velocity
// In the particle's creation expression:
particleShape1.velocity = rand(-2, 2);
particleShape1.velocityY = rand(1, 5);

// Runtime expression - add gravity and turbulence
// In the particle's runtime expression:
particleShape1.velocityY += -0.5 * time;
particleShape1.velocity += rand(-0.1, 0.1);
particleShape1.position += particleShape1.velocity;

// Fade particles based on age
float $age = particleShape1.age / particleShape1.lifespan;
particleShape1.opacity = 1 - $age;

// Change color over lifetime
if ($age < 0.3) {
    particleShape1.color = <<1, 0.5, 0>>;  // Orange
} else if ($age < 0.7) {
    particleShape1.color = <<1, 0.8, 0>>;  // Yellow
} else {
    particleShape1.color = <<0.5, 0, 0>>;  // Dark red
}
```

## Code Review Guide

When reviewing MEL scripts, focus on:

### Code Quality
- **Readability** – Are variables and procedures named clearly? Are there comments?
- **Efficiency** – Are there unnecessary loops or commands?
- **Error Handling** – Does the script handle edge cases (e.g., no selection)?
- **Naming Conventions** – Are names clear (e.g., `$radius` not `$r`)?

### Maya‑Specific Practices
- **UI Design** – Is the UI intuitive and well‑organized?
- **Performance** – Are expressions efficient (avoid heavy computations per frame)?
- **Node Management** – Are nodes properly named to avoid conflicts?

### Example Review Note

<div class="review-note">

<strong>🔍 Code Review Example:</strong>

```mel
proc createStuff() {
    string $sel[] = `ls -sl`;
    for ($i=0;$i<size($sel);$i++) {
        move 0 $i*2 0 $sel[$i];
    }
}
```

<span class="badge">Good</span> Clear purpose (moves selected objects upward in a step pattern).

<span class="badge danger">Bad</span> No error handling if nothing is selected. Add a check:
```mel
if (size(`ls -sl`) == 0) {
    warning "No objects selected!";
    return;
}
```

## Week 1: Probability Foundations

This week reviews and deepens understanding of probability theory, establishing the rigorous mathematical foundation for all subsequent statistical methods.

### Kolmogorov Probability Space

A probability space is a triple `(Ω, ℱ, P)` where:

- **Ω** (sample space) - set of all possible outcomes
- **ℱ** (event space) - σ-algebra of subsets of Ω
- **P** (probability measure) - function `P: ℱ → [0,1]` satisfying:
  1. `P(Ω) = 1`
  2. For disjoint `A₁, A₂, ...`, `P(∪Aᵢ) = ΣP(Aᵢ)`

```python
# Example: Tossing two dice - building sample space
import itertools

# Sample space for two dice
Ω = [(i, j) for i in range(1, 7) for j in range(1, 7)]

# Event: sum equals 7
event_A = [outcome for outcome in Ω if sum(outcome) == 7]

# Probability
P_A = len(event_A) / len(Ω)
print(f"P(sum=7) = {P_A}")  # 6/36 = 1/6
```

### Conditional Probability and Independence

For events A and B with P(B) > 0:

```
P(A|B) = P(A∩B) / P(B)
```

Events A and B are independent iff:
```
P(A∩B) = P(A) · P(B)
```

## Week 2: Random Variables and Distributions

Random variables formalize the mapping from outcomes to numerical values. This week covers univariate and multivariate distributions.

### Distribution Functions

The **cumulative distribution function (CDF)** of random variable X:

```
F(x) = P(X ≤ x) = P({ω: X(ω) ≤ x})
```

For continuous variables, the **probability density function (PDF)**:
```
f(x) = F'(x)
```

### Important Distributions

| Distribution | Parameters | Support | Applications |
|--------------|------------|---------|--------------|
| Normal | μ, σ² | ℝ | Natural phenomena, errors |
| Binomial | n, p | \{0,...,n\} | Count of successes |
| Poisson | λ | ℕ₀ | Rare events, counts |
| Exponential | λ | ℝ⁺ | Waiting times |
| Chi-squared | k | ℝ⁺ | Variance estimation |

```python
import numpy as np
from scipy import stats

# Generate normal distribution samples
X = np.random.normal(loc=0, scale=1, size=1000)

# Empirical vs theoretical CDF comparison
x_vals = np.linspace(-3, 3, 100)
emp_cdf = [np.mean(X <= x) for x in x_vals]
theoretical_cdf = stats.norm.cdf(x_vals)
```

## Week 3: Descriptive Statistics

Descriptive statistics summarize and describe the main features of a dataset.

### Statistical Ensemble

A **statistical ensemble** (statistický soubor) is a collection of statistical units. We distinguish between:
- **Population**: All units of interest
- **Sample**: A subset of the population

### Numerical Characteristics

**Measures of Central Tendency:**
- Mean: `μ = (1/n) Σ xᵢ`
- Median: middle value when sorted
- Mode: most frequent value

**Measures of Dispersion:**
- Variance: `σ² = (1/n) Σ (xᵢ - μ)²`
- Standard deviation: `σ = √σ²`
- Range: `max - min`
- Interquartile range (IQR): `Q₃ - Q₁`

**Measures of Shape:**
- Skewness: asymmetry
- Kurtosis: tail heaviness

```python
import numpy as np
from scipy import stats

# Sample data
data = np.array([1.5, 2.1, 2.3, 2.5, 2.7, 2.8, 3.0, 3.5, 4.2, 5.1])

# Basic statistics
mean = np.mean(data)
median = np.median(data)
variance = np.var(data, ddof=1)  # sample variance
std_dev = np.std(data, ddof=1)
skewness = stats.skew(data)
kurtosis = stats.kurtosis(data)

print(f"Mean: {mean:.2f}, Median: {median:.2f}")
print(f"Variance: {variance:.2f}, Std Dev: {std_dev:.2f}")
print(f"Skewness: {skewness:.2f}, Kurtosis: {kurtosis:.2f}")
```

## Week 4: Data Visualization and Transformation

Effective visualization is crucial for understanding and communicating statistical findings.

### Histogram Construction

**Steps for constructing a histogram:**
1. Determine the number of bins (Sturges' rule: `k = 1 + 3.322 log₁₀(n)`)
2. Calculate bin width: `h = (max - min) / k`
3. Count frequencies in each bin
4. Plot frequencies (or relative frequencies)

### Boxplot (Box-and-Whisker Plot)

A boxplot displays the five-number summary:
- Minimum (or lower whisker)
- First quartile (Q₁)
- Median (Q₂)
- Third quartile (Q₃)
- Maximum (or upper whisker)

**Outliers** are points beyond:
- Lower bound: `Q₁ - 1.5 × IQR`
- Upper bound: `Q₃ + 1.5 × IQR`

```python
import matplotlib.pyplot as plt
import seaborn as sns

# Create histogram and boxplot side by side
fig, (ax1, ax2) = plt.subplots(1, 2, figsize=(12, 4))

# Histogram
ax1.hist(data, bins='auto', edgecolor='black')
ax1.set_title('Histogram')
ax1.set_xlabel('Value')
ax1.set_ylabel('Frequency')

# Boxplot
ax2.boxplot(data)
ax2.set_title('Boxplot')
ax2.set_ylabel('Value')

plt.show()
```

### Galton's Ogive

The **ogive** (Galtonova ogiva) is a cumulative frequency curve that helps visualize the distribution's cumulative nature.

## Week 5: Bivariate Statistics and Correlation

When analyzing relationships between two variables, we need specialized tools.

### Contingency Tables

A **contingency table** (četnostní tabulka) displays the frequency distribution of two categorical variables.

| | Category B₁ | Category B₂ | Total |
|---|---|---|---|
| Category A₁ | n₁₁ | n₁₂ | n₁• |
| Category A₂ | n₂₁ | n₂₂ | n₂• |
| Total | n•₁ | n•₂ | n•• |

### Correlation Measures

**Pearson Correlation Coefficient:**
```
r = Σ(xᵢ - x̄)(yᵢ - ȳ) / √[Σ(xᵢ - x̄)² · Σ(yᵢ - ȳ)²]
```

**Spearman Rank Correlation** - nonparametric alternative based on ranks.

**Kendall's Tau** - another nonparametric measure of association.

### Variance-Covariance Matrix

For a vector X = (X₁, X₂, ..., Xₚ):

```
Σ = [Cov(Xᵢ, Xⱼ)]
```

Where `Cov(Xᵢ, Xⱼ) = E[(Xᵢ - μᵢ)(Xⱼ - μⱼ)]`

```python
import numpy as np
import pandas as pd

# Create correlated data
np.random.seed(42)
X = np.random.normal(0, 1, 100)
Y = 0.7 * X + np.random.normal(0, 0.3, 100)

# Correlation matrix
data = pd.DataFrame({'X': X, 'Y': Y})
correlation_matrix = data.corr()

print("Correlation Matrix:")
print(correlation_matrix)
```

## Week 6: Goodness-of-Fit and Normality Tests

Testing whether data follows a specific distribution is crucial for many statistical procedures.

### Chi-Square Goodness-of-Fit Test

Tests whether observed frequencies match expected frequencies from a theoretical distribution.

**Test Statistic:**
```
χ² = Σ (Oᵢ - Eᵢ)² / Eᵢ
```

**Degrees of freedom:** `df = k - 1 - m` where:
- k = number of categories
- m = number of estimated parameters

### Tests of Normality

**Shapiro-Wilk Test:**
- Best for small to medium samples
- H₀: data comes from a normal distribution

**Anderson-Darling Test:**
- More sensitive to deviations in tails
- Used in many statistical packages

**Kolmogorov-Smirnov Test:**
- Compares empirical CDF to theoretical CDF
- Can be used for any continuous distribution

```python
from scipy import stats

# Test for normality
data = np.random.normal(0, 1, 100)

# Shapiro-Wilk test
stat, p_value = stats.shapiro(data)
print(f"Shapiro-Wilk: statistic={stat:.3f}, p-value={p_value:.3f}")

# Anderson-Darling test
result = stats.anderson(data, dist='norm')
print(f"Anderson-Darling: statistic={result.statistic:.3f}")

# Kolmogorov-Smirnov test
stat, p_value = stats.kstest(data, 'norm')
print(f"K-S test: statistic={stat:.3f}, p-value={p_value:.3f}")
```

## Week 7: Nonparametric Tests

Nonparametric tests don't assume a specific distribution, making them robust for real-world data.

### Sign Test

Simple test comparing matched pairs. Count positive vs. negative differences.

**Test statistic:** Number of positive signs
**H₀:** Median difference = 0

### Wilcoxon Signed-Rank Test

More powerful than the sign test as it considers the magnitude of differences.

**Steps:**
1. Calculate differences Dᵢ = Xᵢ - Yᵢ
2. Rank absolute values
3. Sum ranks for positive and negative differences
4. Test statistic: min(W⁺, W⁻)

### Kruskal-Wallis Test

Nonparametric alternative to one-way ANOVA.

**Test statistic:**
```
H = [12/(N(N+1))] · Σ [Rᵢ²/nᵢ] - 3(N+1)
```

Where Rᵢ is the sum of ranks for group i.

### Friedman Test

Nonparametric test for repeated measures or matched groups.

```python
from scipy import stats

# Example: Kruskal-Wallis test
group1 = np.random.normal(10, 2, 30)
group2 = np.random.normal(12, 2, 30)
group3 = np.random.normal(11, 2, 30)

stat, p_value = stats.kruskal(group1, group2, group3)
print(f"Kruskal-Wallis: H={stat:.3f}, p={p_value:.3f}")
```

## Week 8: Price Indices and Time Series

This week introduces economic indices and basic time series concepts.

### Price Indices

**Laspeyres Index:**
```
L = (Σ pᵢₜ · qᵢ₀) / (Σ pᵢ₀ · qᵢ₀) × 100
```
Uses base-year quantities as weights.

**Paasche Index:**
```
P = (Σ pᵢₜ · qᵢₜ) / (Σ pᵢ₀ · qᵢₜ) × 100
```
Uses current-year quantities as weights.

**Fisher's Ideal Index:**
```
F = √(L × P)
```

### Goods Baskets

A **goods basket** (koš zboží) is a fixed set of goods and services used to track price changes over time.

```python
def laspeyres(prices_t, prices_0, quantities_0):
    """Calculate Laspeyres price index"""
    numerator = sum(prices_t * quantities_0)
    denominator = sum(prices_0 * quantities_0)
    return (numerator / denominator) * 100

def paasche(prices_t, prices_0, quantities_t):
    """Calculate Paasche price index"""
    numerator = sum(prices_t * quantities_t)
    denominator = sum(prices_0 * quantities_t)
    return (numerator / denominator) * 100

# Example
p0 = np.array([10, 20, 30])  # base prices
p1 = np.array([12, 22, 28])  # current prices
q0 = np.array([5, 3, 4])     # base quantities
q1 = np.array([6, 4, 3])     # current quantities

L = laspeyres(p1, p0, q0)
P = paasche(p1, p0, q1)
F = np.sqrt(L * P)

print(f"Laspeyres: {L:.2f}")
print(f"Paasche: {P:.2f}")
print(f"Fisher: {F:.2f}")
```

## Week 9: Time Series Analysis

Time series analysis involves studying data points collected over time.

### Moving Averages

Simple Moving Average (SMA):
```
MAₜ = (1/k) Σᵢ₌₀ᵏ⁻¹ Xₜ₋ᵢ
```

**Centered Moving Average** - used for seasonal adjustment.

### Exponential Smoothing

**Single Exponential Smoothing:**
```
Sₜ = α · Xₜ + (1-α) · Sₜ₋₁
```

**Holt's Method** - adds trend component:
```
Sₜ = α·Xₜ + (1-α)·(Sₜ₋₁ + Tₜ₋₁)
Tₜ = β·(Sₜ - Sₜ₋₁) + (1-β)·Tₜ₋₁
```

**Holt-Winters Method** - adds seasonal component.

### Technical Indicators

**Relative Strength Index (RSI):**
```
RSI = 100 - 100/(1 + RS)
```
Where RS = average gain / average loss over a period.

**Moving Average Convergence Divergence (MACD)** - difference between two EMAs.

```python
import numpy as np
import matplotlib.pyplot as plt

# Generate time series data
dates = pd.date_range('2023-01-01', periods=100, freq='D')
values = 100 + np.cumsum(np.random.normal(0, 0.5, 100))

# Calculate moving averages
window = 7
ma = np.convolve(values, np.ones(window)/window, mode='valid')

# Plot
plt.figure(figsize=(12, 6))
plt.plot(dates, values, label='Original')
plt.plot(dates[window-1:], ma, label=f'MA({window})')
plt.legend()
plt.show()
```

## Week 10: Linear Regression

Linear regression models the relationship between variables using a linear equation.

### History of Regression Methods

**Bošković Method (1757):**
- Minimize sum of absolute deviations
- Precursor to modern L1 regression

**Lambert Method (1760):**
- Contribution to the method of least squares

**Laplace Method (1774):**
- Minimize sum of absolute errors
- Rediscovered multiple times

**Method of Least Squares (Gauss, Legendre):**
- Minimize sum of squared errors
- This became the standard

### Ordinary Least Squares (OLS)

Model: `Y = Xβ + ε`

Estimator: `β̂ = (X'X)⁻¹X'Y`

**Assumptions:**
1. Linearity
2. Independence of errors
3. Homoscedasticity
4. No multicollinearity
5. Normality of errors (for inference)

```python
import statsmodels.api as sm
import pandas as pd

# Generate data
X = np.random.normal(0, 1, (100, 2))
beta = np.array([2.0, 3.0])
y = X @ beta + np.random.normal(0, 0.5, 100)

# Fit OLS model
X_with_const = sm.add_constant(X)
model = sm.OLS(y, X_with_const).fit()

# Summary
print(model.summary())
```

## Week 11: Nonlinear and Orthogonal Regression

### Nonlinear Regression

Models where the relationship isn't linear in parameters:

Examples:
- **Exponential:** `y = a·exp(b·x)`
- **Power:** `y = a·xᵇ`
- **Logistic:** `y = L/(1 + exp(-k·(x - x₀)))`

**Methods:**
1. Linearization via transformation
2. Iterative methods (Newton-Raphson, Gauss-Newton)

### Orthogonal Regression

When both x and y have measurement errors:

**Total Least Squares (TLS):**
- Minimizes perpendicular distances to the regression line
- Appropriate when both variables are measured with error

**Principal Component Analysis approach:**
- First principal component gives the regression direction

```python
from scipy.optimize import curve_fit

# Nonlinear model: exponential growth
def exp_model(x, a, b):
    return a * np.exp(b * x)

# Generate data
x_data = np.linspace(0, 5, 50)
y_data = 2 * np.exp(0.3 * x_data) + np.random.normal(0, 0.1, 50)

# Fit nonlinear model
popt, pcov = curve_fit(exp_model, x_data, y_data)
a_est, b_est = popt

print(f"Estimated a: {a_est:.3f}, b: {b_est:.3f}")
```

## Week 12: ANOVA and Experimental Design

### Analysis of Variance (ANOVA)

ANOVA partitions total variance into components:

**Total Sum of Squares:**
```
SST = Σ(Yᵢⱼ - Ȳ)²
```

**Between Groups:**
```
SSB = Σ nⱼ(Ȳⱼ - Ȳ)²
```

**Within Groups:**
```
SSW = Σ(Yᵢⱼ - Ȳⱼ)²
```

**F-statistic:**
```
F = (SSB/(k-1)) / (SSW/(n-k))
```

### Planned Experiments

**One-way ANOVA:** One factor at multiple levels

**Two-way ANOVA:** Two factors with possible interaction

**Repeated Measures:** Same subjects measured multiple times

**Design Principles:**
1. Randomization
2. Replication
3. Blocking
4. Factorial design

```python
from scipy import stats

# One-way ANOVA example
groups = [
    np.random.normal(10, 2, 30),
    np.random.normal(12, 2, 30),
    np.random.normal(11, 2, 30)
]

f_stat, p_value = stats.f_oneway(*groups)
print(f"F-statistic: {f_stat:.3f}, p-value: {p_value:.3f}")

# Post-hoc tests (Tukey HSD)
from statsmodels.stats.multicomp import pairwise_tukeyhsd

# Combine data
all_data = np.concatenate(groups)
all_groups = np.repeat(['A', 'B', 'C'], [30, 30, 30])

tukey = pairwise_tukeyhsd(all_data, all_groups, alpha=0.05)
print(tukey)
```

## Week 13: Multivariate Methods

### Principal Component Analysis (PCA)

**Goal:** Reduce dimensionality while preserving variance.

**Steps:**
1. Standardize variables
2. Compute correlation matrix (or covariance matrix)
3. Find eigenvectors and eigenvalues
4. Sort components by eigenvalue
5. Project data onto principal components

```python
from sklearn.decomposition import PCA
from sklearn.preprocessing import StandardScaler

# Sample data (multiple variables)
X = np.random.randn(100, 5)

# Standardize
scaler = StandardScaler()
X_scaled = scaler.fit_transform(X)

# Apply PCA
pca = PCA(n_components=3)
X_pca = pca.fit_transform(X_scaled)

# Explained variance
print(f"Explained variance: {pca.explained_variance_ratio_}")
print(f"Loadings: \n{pca.components_}")
```

### Factor Analysis

**Goal:** Identify latent (unobserved) factors underlying observed variables.

**Model:** `X = ΛF + ε`
- X: observed variables
- Λ: factor loadings matrix
- F: common factors
- ε: unique factors

### Cluster Analysis

**Purpose:** Group similar observations together.

**Distance Measures:**
- Euclidean: `√[Σ(xᵢ - yᵢ)²]`
- Manhattan: `Σ|xᵢ - yᵢ|`
- Minkowski: `[Σ|xᵢ - yᵢ|ᵖ]¹/ᵖ`
- Mahalanobis: accounts for covariance

**Hierarchical Clustering:**
1. Agglomerative (bottom-up)
2. Divisive (top-down)

**Non-hierarchical Clustering:**
- K-means
- K-medoids (PAM)

```python
from sklearn.cluster import KMeans
from scipy.cluster.hierarchy import dendrogram, linkage

# K-means clustering
kmeans = KMeans(n_clusters=3, random_state=42)
clusters = kmeans.fit_predict(X_scaled)

# Hierarchical clustering
linkage_matrix = linkage(X_scaled, method='ward')
dendrogram(linkage_matrix)

plt.title('Dendrogram')
plt.show()
```

### Common Statistical Formulas

**Standard Error:**
```
SE = σ / √n
```

**Confidence Interval (95%):**
```
x̄ ± 1.96 · SE
```

**t-statistic:**
```
t = (x̄ - μ₀) / (s/√n)
```

**Sample Variance:**
```
s² = Σ(xᵢ - x̄)² / (n-1)
```

**F-statistic (ANOVA):**
```
F = MSB / MSW
```

**Correlation Coefficient:**
```
r = Σ(xᵢ - x̄)(yᵢ - ȳ) / √[Σ(xᵢ - x̄)² · Σ(yᵢ - ȳ)²]
```

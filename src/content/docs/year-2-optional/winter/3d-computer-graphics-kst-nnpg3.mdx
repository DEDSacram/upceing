## Week 1: Introduction to 3D Graphics

3D graphics turns scene descriptions (geometry + materials + lights + camera) into 2D images through a fixed sequence of spaces and tests.

### Fundamental Terms

- **Vertex** — point with attributes (position, normal, UV, colour).
- **Primitive** — point, line, triangle (GPUs love triangles).
- **Mesh** — connected primitives sharing vertices.
- **Scene graph** — hierarchy of transforms (arm → forearm → hand).
- **Rasterisation** — converting projected triangles to fragments (pixels-in-waiting).

### The Pipeline at a Glance

```
Model space -> [Model] -> World -> [View] -> Camera -> [Projection]
  -> Clip space -> perspective divide -> NDC -> viewport -> Screen
  -> rasterise -> fragment shader -> depth/stencil tests -> framebuffer
```

### Spaces Cheat Table

| Space | Coordinates | Defined by |
|-------|------------|-----------|
| Model | Object-local | Artist |
| World | Scene-global | Model matrices |
| View/camera | Camera at origin, −Z forward | View matrix |
| Clip | Homogeneous `w` kept | Projection matrix |
| NDC | Divided by `w`, [−1, 1] | Hardware |
| Screen | Pixels | Viewport |

```c
// Minimal modern OpenGL triangle (C + GLFW + GLAD, excerpt)
float verts[] = { -0.5f,-0.5f,0.0f,  0.5f,-0.5f,0.0f,  0.0f,0.5f,0.0f };
```

## Week 2: Colours and Light

Colour is physics (spectra) mapped through biology (cones) into numbers (RGB) — and every step can surprise you.

### Colour Spaces

| Space | Channels | Use |
|-------|----------|-----|
| sRGB | R,G,B (gamma-encoded) | Displays, textures |
| Linear RGB | R,G,B (physical light) | Lighting math — convert before shading! |
| HSV/HSL | Hue, saturation, value | UI pickers |
| CIE XYZ / Lab | Perceptual | Colour difference metrics |

> **Rule:** Do lighting in linear space, store/display in sRGB. Forgetting the conversion washes out or crushes every render.

### Light Components (Phong)

`I = ambient + diffuse·max(N·L,0) + specular·max(R·V,0)^shininess` — Blinn-Phong replaces `R·V` with `N·H` (half-vector), cheaper and smoother.

### Gamma

```glsl
// sRGB <-> linear helpers (fragment shader)
vec3 toLinear(vec3 c) { return pow(c, vec3(2.2)); }
vec3 toSRGB(vec3 c)   { return pow(c, vec3(1.0 / 2.2)); }
```

```glsl
// Blinn-Phong fragment shader (linear space lighting)
#version 330 core
in vec3 vN; in vec3 vPos; in vec2 vUV;
out vec4 FragColor;
uniform vec3 uLightPos, uViewPos, uLightColor, uAlbedo;
uniform float uShininess;
void main() {
    vec3 N = normalize(vN), L = normalize(uLightPos - vPos);
    vec3 V = normalize(uViewPos - vPos), H = normalize(L + V);
    float diff = max(dot(N, L), 0.0);
    float spec = pow(max(dot(N, H), 0.0), uShininess);
    vec3 lin = uAlbedo * (0.1 + diff) * uLightColor + spec * uLightColor;
    FragColor = vec4(pow(lin, vec3(1.0 / 2.2)), 1.0); // back to sRGB
}
```

## Week 3: Modeling Tools — Autodesk Maya

Maya organises everything as nodes in a dependency graph: transform nodes position, shape nodes hold geometry, shader nodes shade.

### Interface Essentials

- **Viewports** — persp/top/front/side, wireframe/shaded/X-ray toggles.
- **Outliner / Hypergraph** — scene hierarchy vs full dependency graph.
- **Channel Box + Attribute Editor** — fast numeric edits vs full node control.
- **Shelf + Hotbox** — keep extrusion, bevel, bridge on speed-dial.

### Core Primitive Workflow

1. Create primitive (cube, cylinder, sphere) with sane subdivisions.
2. Freeze transforms, delete history before export milestones.
3. Model half + mirror (symmetry), keep quads, avoid n-gons on deforming parts.
4. Name everything (`chr_hand_L_geo`); groups mirror the future rig.

### Scene Hygiene Checklist

| Check | Command / action |
|-------|-----------------|
| Frozen transforms | Modify → Freeze Transformations |
| Clean history | Edit → Delete by Type → History |
| No n-gons in bend areas | Mesh → Cleanup |
| Units + grid | centimetres, power-of-two textures |
| Named materials | `mat_metal_dark`, not `blinn3` |

## Week 4: Modeling of 3D Objects

Good topology deforms, subdivides and shades predictably; bad topology fights every later step.

### Mesh Rules

- Prefer **quads**; triangles are acceptable on flat rigid parts; n-gons invite shading artefacts.
- **Edge loops** follow muscles/joints (eyes, mouth, knuckles, elbows).
- Even density: sudden subdivision jumps cause pinching under smoothing.
- Poles (valence ≠ 4) belong on flat areas, never in bend zones.

### NURBS vs Polygons

| Aspect | NURBS | Polygons |
|--------|-------|----------|
| Surface | Exact smooth patches | Approximated facets |
| Editing | CVs, weights, trim curves | Vertices, edges, sculpt |
| Best for | Car bodies, bottles | Characters, game assets |
| Export | Tessellate at render time | Direct to GPU |

### UV Mapping Basics

Unwrap with minimal stretching (checker preview!), pack islands with padding for mip bleeding, keep texel density uniform across hero parts.

```mel

createRenderNode -asShader surfaceShader -n checkerMat;
```

## Week 6: OpenGL Pipeline, Primitives and Structures

Modern OpenGL = you own the buffers and shaders; the fixed function pipeline is gone.

### Buffer Objects

| Object | Holds | Notes |
|--------|-------|-------|
| VBO | Vertex attributes | `GL_STATIC_DRAW` vs `GL_DYNAMIC_DRAW` |
| EBO | Indices | Saves memory, enables shared verts |
| VAO | Attribute layout state | Bind once, draw many |
| UBO/SSBO | Uniform blocks / storage | Camera data, particle arrays |
| FBO | Off-screen targets | Post-processing, shadow maps |

### Draw Path

VAO bind → program use → uniforms → `glDrawElements` → vertex shader per vertex → clipping/culling → rasterisation → fragment shader per fragment → depth/stencil/blend → framebuffer.

## Week 7: OpenGL Shaders

Shaders are small programs on the GPU: vertex (geometry transform), fragment (colour), plus optional geometry/tessellation/compute stages.

### Stage Responsibilities

| Stage | Input → Output | Typical job |
|-------|---------------|-------------|
| Vertex | attributes → clip pos + varyings | MVP transform, normals |
| (Tessellation) | patches → denser mesh | Curve/surface subdivision |
| (Geometry) | primitives → new primitives | Billboards, wireframe |
| Fragment | interpolated varyings → colour | Lighting, texturing |
| (Compute) | buffers → buffers | Particles, culling |

### Uniforms and Varyings

```glsl
// vertex: MVP + normal matrix + UV passthrough
#version 330 core
layout (location = 0) in vec3 aPos;
layout (location = 1) in vec3 aNormal;
layout (location = 2) in vec2 aUV;
out vec3 vN; out vec3 vPos; out vec2 vUV;
uniform mat4 uModel, uView, uProj;
void main() {
    vec4 world = uModel * vec4(aPos, 1.0);
    vPos = world.xyz;
    vN = mat3(transpose(inverse(uModel))) * aNormal;
    vUV = aUV;
    gl_Position = uProj * uView * world;
}
```

```glsl
// fragment: texture * Blinn-Phong (pairs with vertex above)
#version 330 core
in vec3 vN; in vec3 vPos; in vec2 vUV;
out vec4 FragColor;
uniform sampler2D uTex; uniform vec3 uLightPos, uViewPos;
void main() {
    vec3 albedo = texture(uTex, vUV).rgb;
    vec3 N = normalize(vN), L = normalize(uLightPos - vPos);
    vec3 V = normalize(uViewPos - vPos), H = normalize(L + V);
    float dif = max(dot(N, L), 0.0), spec = pow(max(dot(N, H), 0.0), 64.0);
    FragColor = vec4(albedo * (0.08 + dif) + spec * 0.4, 1.0);
}
```

## Week 8: Curves

Curves define paths, profiles, animations — and surfaces are just curves swept through space.

### Bézier Essentials

Cubic Bézier: `B(t) = (1−t)³P0 + 3(1−t)²tP1 + 3(1−t)t²P2 + t³P3`. de Casteljau evaluates stably; Bernstein form differentiates cleanly. B-splines join segments with continuity control; NURBS add weights (exact circles/conics).

### Continuity Ladder

| Level | Guarantees | Visible artefact if broken |
|-------|-----------|---------------------------|
| C⁰/G⁰ | Points meet | Crack |
| C¹/G¹ | Tangents align | Shading seam / velocity jump |
| C² | Curvature continuous | Reflection wobble |

```python
# Cubic Bezier evaluation (de Casteljau) — also handy for CPU-side tessellation
def bezier(p0, p1, p2, p3, t):
    a = tuple((1-t)*a + t*b for a, b in zip(p0, p1))
    b = tuple((1-t)*a + t*b for a, b in zip(p1, p2))
    c = tuple((1-t)*a + t*b for a, b in zip(p2, p3))
    d = tuple((1-t)*a + t*b for a, b in zip(a, b))
    e = tuple((1-t)*a + t*b for a, b in zip(b, c))
    return tuple((1-t)*a + t*b for a, b in zip(d, e))

print([round(bezier((0,0),(1,2),(3,2),(4,0),t)[0], 2) for t in (0, .5, 1)])
```

```glsl
// Tessellation evaluation shader idea (eval along u, patches from control points)
#version 410 core
layout(isolines) in;
uniform mat4 uMVP;
void main() {
    float u = gl_TessCoord.x;
    vec4 p0 = gl_in[0].gl_Position, p1 = gl_in[1].gl_Position;
    vec4 p2 = gl_in[2].gl_Position, p3 = gl_in[3].gl_Position;
    vec4 p = (1.-u)*(1.-u)*(1.-u)*p0 + 3.*(1.-u)*(1.-u)*u*p1
           + 3.*(1.-u)*u*u*p2 + u*u*u*p3;
    gl_Position = uMVP * p;
}
```

## Week 9: Textures

Textures are functions over surfaces: colour today, normals/roughness/AO tomorrow.

### Sampling Pipeline

UV → wrap (repeat/mirror/clamp) → min/mag filter → mipmap level → texel → (sRGB decode) → shader.

| Choice | Options | Avoid |
|--------|---------|-------|
| Min filter | Nearest / linear / mipmap variants | Non-mipmapped minification (shimmer) |
| Mipmaps | Generated, bias-tunable | Missing mips on NPOT without support |
| Anisotropy | 1–16× | Grazing-angle blur without it |
| Seams | Padding, mirrored UVs | Bleeding across atlas neighbours |

```c
// Texture upload with mipmaps + anisotropy (stb_image assumed)
int w, h, ch; unsigned char *px = stbi_load("brick.png", &w, &h, &ch, 4);
GLuint tex; glGenTextures(1, &tex); glBindTexture(GL_TEXTURE_2D, tex);
glTexImage2D(GL_TEXTURE_2D, 0, GL_SRGB8_ALPHA8, w, h, 0, GL_RGBA, GL_UNSIGNED_BYTE, px);
glGenerateMipmap(GL_TEXTURE_2D);
glTexParameteri(GL_TEXTURE_2D, GL_TEXTURE_MIN_FILTER, GL_LINEAR_MIPMAP_LINEAR);
glTexParameteri(GL_TEXTURE_2D, GL_TEXTURE_MAG_FILTER, GL_LINEAR);
glTexParameteri(GL_TEXTURE_2D, GL_TEXTURE_WRAP_S, GL_REPEAT);
glTexParameteri(GL_TEXTURE_2D, GL_TEXTURE_WRAP_T, GL_REPEAT);

glTexParameterf(GL_TEXTURE_2D, GL_TEXTURE_MAX_ANISOTROPY, maxAniso > 8 ? 8 : maxAniso);
```

## Week 10: Transformations

One matrix chain rules every vertex: `clip = P · V · M · position`.

### Homogeneous Matrices

| Transform | 4×4 form | Notes |
|-----------|----------|-------|
| Translation | Identity + `t` in last column | Order matters! |
| Rotation | 3×3 orthonormal | Use quaternions to compose/lerp |
| Scale | Diagonal | Non-uniform breaks normals (use normal matrix) |
| Projection | Perspective / ortho | Bakes depth mapping |

### Composition Order (Column-Major GLM)

```c
// C / GLM-style: orbit camera + spinning model
mat4 model = rotate_y(time) * translate(2.0f, 0.0f, 0.0f) * scale(0.5f);
mat4 view  = look_at(eye, center, up);
mat4 proj  = perspective(radians(45.0f), aspect, 0.1f, 100.0f);
mat4 mvp   = proj * view * model;
glUniformMatrix4fv(uMVP, 1, GL_FALSE, mvp.data);
```

```glsl
// Normal matrix done right (non-uniform scale safe)
vN = mat3(transpose(inverse(uModel))) * aNormal;
```

### Quaternions in Brief

Compact, gimbal-lock-free rotations; `slerp` interpolates orientations smoothly — the backbone of skeletal animation (Week 13).

## Week 11: Screening

"Screening" here = everything between clip space and pixels: clipping, viewport mapping, culling, depth/stencil, blending and picking.

### Clip → Screen Chain

1. **Clipping** — Cohen–Sutherland (lines) / Sutherland–Hodgman (polygons) against the view volume.
2. **Perspective divide** — `/w` → NDC.
3. **Viewport transform** — NDC → window pixels (`glViewport`).
4. **Per-fragment tests** — scissor → stencil → depth → blending → framebuffer.

### Culling and Depth

| Technique | Culls | Cost |
|-----------|-------|------|
| Back-face culling | Wrong-winding triangles | Free-ish, needs consistent winding |
| Frustum culling (CPU) | Off-screen objects | Bounding-volume tests |
| Occlusion culling | Hidden objects | Queries / Hi-Z |
| Depth test | Hidden fragments | Per-fragment, hardware-fast |

```c
// Viewport split + picking via scissor + unproject
glViewport(0, 0, w/2, h);          // left: solid
// draw scene...
glViewport(w/2, 0, w/2, h);        // right: wireframe overlay
glPolygonMode(GL_FRONT_AND_BACK, GL_LINE);
// draw scene again...
// picking: read depth + unproject
float depth; glReadPixels(mx, my, 1, 1, GL_DEPTH_COMPONENT, GL_FLOAT, &depth);
// world = inverse(P*V) * vec4(ndcX, ndcY, depth*2-1, 1); divide by w
```

## Week 12: Projection, Shadows and Shading

Projection shapes perception (perspective drama vs CAD precision); shadows anchor objects; shading models sell materials.

### Projection Methods

| Projection | Matrix character | Use |
|------------|-----------------|-----|
| Perspective | Converging, `w = −z` | Games, film |
| Orthographic | Parallel, no foreshortening | CAD, UI, shadow maps (directional) |
| Oblique | Sheared ortho | Technical illustration |
| Fisheye/curvilinear | Non-linear (custom shader) | VR, stylised |

### Shadow Mapping in Two Passes

1. Render depth from the light into a texture.
2. In the main pass, transform fragments into light space; compare depth (with bias + PCF filtering).

```glsl
// Pass 2 fragment: PCF shadow lookup
#version 330 core
uniform sampler2DShadow uShadowMap;
in vec4 vLightSpace;
float shadowFactor() {
    vec3 coord = vLightSpace.xyz / vLightSpace.w * 0.5 + 0.5;
    float sum = 0.0;
    vec2 texel = 1.0 / textureSize(uShadowMap, 0);
    for (int x = -1; x <= 1; ++x)
        for (int y = -1; y <= 1; ++y)
            sum += texture(uShadowMap, vec3(coord.xy + vec2(x, y) * texel, coord.z - 0.001));
    return sum / 9.0;
}
```

### Shading Models Compared

| Model | Cost | Strength |
|-------|------|----------|
| Flat | 1 normal/face | Faceted style |
| Gouraud | Per-vertex lighting | Cheap, misses speculars |
| Phong/Blinn-Phong | Per-fragment | Classic balanced |
| PBR (metal/rough) | Textures + IBL | Physical plausibility |

### Keyframes and Interpolation

| Interpolant | Continuity | Use |

### Skeletal Skinning (Linear Blend)

`v' = Σ w_i · B_i · v` — each vertex follows a weighted mix of bone matrices; normalise weights, keep ≤ 4 influences for GPUs.

```glsl
// GPU skinning vertex excerpt (max 4 bones)
#version 330 core
layout(location=0) in vec3 aPos;
layout(location=3) in ivec4 aBones;
layout(location=4) in vec4 aWeights;
uniform mat4 uBones[64]; uniform mat4 uMVP;
void main() {
    mat4 skin = aWeights.x * uBones[aBones.x] + aWeights.y * uBones[aBones.y]
              + aWeights.z * uBones[aBones.z] + aWeights.w * uBones[aBones.w];
    gl_Position = uMVP * skin * vec4(aPos, 1.0);
}
```

Cloth/hair: verlet integration + constraints. Particles: spawn → integrate → fade, all in a compute/vertex shader for thousands of sparks, smoke, rain.

```c
// CPU animation clock: loop, ping-pong, ease
float t = fmod(time, duration) / duration;      // loop 0..1
float e = t * t * (3.0f - 2.0f * t);            // smoothstep ease
vec3 pos = mix(keyA, keyB, e);
```

## Code Review Guide

### What to Look For

1. **Space correctness** — lighting in linear, normals via normal matrix, MVP order.
2. **Resource hygiene** — VAO/VBO/texture creation paired with deletion; no per-frame re-uploads.
3. **Shader robustness** — precision, uniform locations checked, compile logs printed.
4. **Topology/UV quality** — quads, no stretching, mips + anisotropy.
5. **Determinism** — `dt`-based animation, aspect-correct projection on resize.

## Week 1: Introduction to Queueing Theory — History and Basic Elements

Brief introduction to mass service systems: from Erlang's telephone exchanges (1909) to modern call centres, networks, and manufacturing.

### History

- **A. K. Erlang (1909)** - telephone traffic, Erlang B/C formulas. <span class="badge">Founder</span>
- **Kendall (1953)** - A/B/c notation for queueing systems
- **Little (1961)** - Little's law L = λW, universal conservation law
- **Modern use** - networks, hospitals, logistics, cloud provisioning

### Basic Elements

| Element | Symbol | Meaning |
|---------|--------|---------|
| Arrival rate | λ | Mean customers arriving per time unit |
| Service rate | μ | Mean services completed per server per time unit |
| Servers | c / n / S | Number of parallel servers |
| Traffic intensity | ρ = λ/(cμ) | Utilization per server (must be < 1 for stability) |
| Queue discipline | FIFO/LIFO/PRI | Order of service |

> **Rule:** Steady state exists only if ρ < 1 (for infinite-queue systems). Always check stability first.

### Little's Law

```python
# Little's law: L = lambda * W, Lq = lambda * Wq
lam = 10.0   # arrivals per hour
W = 0.5      # hours in system
L = lam * W
print(f"Mean number in system L = {L}")
# W = Wq + 1/mu ;  L = Lq + lam/mu
```

## Week 2: Simulation Models and Monte Carlo Method

Simulation replaces intractable analysis. Distinguish physical vs mathematical models and use Monte Carlo sampling.

### Simulation Models

| Model | Description | Example |
|-------|-------------|---------|
| **Physical** | Scaled real object | Wind tunnel, testbed network |
| **Mathematical analytical** | Closed-form equations | M/M/1 formulas |
| **Mathematical simulation** | Event-driven sampling | Discrete-event queue simulator |

### Monte Carlo Method

Estimate expectations by random sampling: exponential inter-arrivals via inverse transform `−ln(U)/λ`.

```python
import random, math, statistics

def simulate_mm1(lam, mu, n=20000):
    t = 0.0
    server_free = 0.0
    waits = []
    for _ in range(n):
        t += random.expovariate(lam)          # next arrival
        service = random.expovariate(mu)      # service time
        start = max(t, server_free)
        waits.append(start - t)
        server_free = start + service
    return statistics.mean(waits)

print("Estimated Wq:", simulate_mm1(lam=8, mu=10))
print("Theory  Wq:", 8 / (10 * (10 - 8)))
```

## Week 3: Markov Chains

Markov chains model memoryless transitions between states (number of customers in system).

### Key Concepts

- **Markov property** - future depends only on present state: `P(Xn+1 | Xn, ..., X0) = P(Xn+1 | Xn)`
- **Discrete-time (DTMC)** - transition matrix P, n-step probabilities via P^n
- **Continuous-time (CTMC)** - birth-death process with rates λn (birth), μn (death); queueing systems are birth-death processes
- **Steady state π** - solves π = πP (DTMC) or balance equations λn·pn = μn+1·pn+1 (CTMC)

| Concept | Formula |
|---------|---------|
| Chapman-Kolmogorov | P^(m+n) = P^m · P^n |
| Global balance (CTMC) | flow out = flow in per state |
| Birth-death solution | pn = p0 · Π(λi/μi+1) |

```python
import numpy as np

P = np.array([[0.7, 0.3],
              [0.4, 0.6]])
# steady state: pi = pi @ P, sum(pi) = 1
w, v = np.linalg.eig(P.T)
pi = np.real(v[:, np.isclose(w, 1)].flatten())
pi = pi / pi.sum()
print("Steady state:", pi)
print("P^10:\n", np.linalg.matrix_power(P, 10))
```

## Week 4: Kendall Classification

Kendall notation compactly describes any queueing system: **A/B/c/K/m/Z**.

### Notation

| Symbol | Meaning | Common values |
|--------|---------|---------------|
| **A** | Arrival distribution | M (exponential), D (deterministic), Ek (Erlang-k), G (general) |
| **B** | Service distribution | M, D, Ek, G |
| **c** | Number of servers | 1, n, ∞ |
| **K** | System capacity | ∞ (default), finite K |
| **m** | Population size | ∞ (default), finite M |
| **Z** | Queue discipline | FIFO (default), LIFO, PRI, SIRO |

Examples: <span class="badge">M/M/1</span> single server infinite queue, <span class="badge">M/M/n/K</span> multi-server finite capacity, <span class="badge danger">M/M/n/n</span> pure loss system.

```python
def kendall(arrival, service, servers, capacity="inf", population="inf", discipline="FIFO"):
    s = f"{arrival}/{service}/{servers}"
    if capacity != "inf" or population != "inf" or discipline != "FIFO":
        s += f"/{capacity}/{population}/{discipline}"
    return s

print(kendall("M", "M", 1))          # M/M/1
print(kendall("M", "M", 3, 50))      # M/M/3/50
print(kendall("M", "D", 2))          # M/D/2
```

## Week 5: M/M/1 System

The fundamental single-server model: Poisson arrivals λ, exponential service μ, ρ = λ/μ < 1.

### Formulas

| Measure | Formula |
|---------|---------|
| Utilization | ρ = λ/μ |
| Empty system | p0 = 1 − ρ |
| n customers | pn = (1−ρ)ρ^n |
| Mean in system | L = ρ/(1−ρ) |
| Mean in queue | Lq = ρ²/(1−ρ) |
| Time in system | W = 1/(μ−λ) |
| Time in queue | Wq = λ/(μ(μ−λ)) |

> **Rule:** Wq explodes as ρ → 1. A server at 90% utilization has L = 9 — small λ increases cause huge queues.

```python
def mm1(lam, mu):
    assert lam < mu, "Unstable: rho >= 1"
    rho = lam / mu
    L = rho / (1 - rho)
    Lq = rho**2 / (1 - rho)
    W = 1 / (mu - lam)
    Wq = lam / (mu * (mu - lam))
    return dict(rho=rho, L=L, Lq=Lq, W=W, Wq=Wq)

for lam in (6, 8, 9.5):
    print(lam, mm1(lam, mu=10))
```

## Week 6: M/M/n System with Infinite Queue

Multiple parallel servers share one unbounded queue (bank counters, checkouts). Erlang C gives waiting probability.

### Key Concepts

- **Stability:** ρ = λ/(nμ) < 1
- **Erlang C** - probability an arrival must wait: C(n, a) where a = λ/μ (offered load)
- **Wq** = C(n,a) / (nμ − λ); **Lq** = λ·Wq; **L** = Lq + a

| n=1 | Reduces to M/M/1 |
|-----|------------------|
| n↑ | Waiting probability drops sharply (pooling effect) |

```python
import math

def erlang_c(n, a):
    # a = lam/mu offered load, rho = a/n < 1
    s = sum(a**k / math.factorial(k) for k in range(n))
    term = a**n / (math.factorial(n) * (1 - a / n))
    return term / (s + term)

def mmn_inf(lam, mu, n):
    a = lam / mu
    assert a / n < 1, "Unstable"
    C = erlang_c(n, a)
    Wq = C / (n * mu - lam)
    Lq = lam * Wq
    return dict(a=a, rho=a/n, C=C, Wq=Wq, Lq=Lq, L=Lq + a)

print(mmn_inf(lam=18, mu=10, n=2))
print(mmn_inf(lam=18, mu=10, n=3))
```

## Week 7: M/M/n System with Finite Queue

Capacity K limits total customers (waiting room size). Arrivals finding K customers are turned away — finite waiting room, proper queue mode.

### Key Concepts

- **State space** 0..K; always stable (losses cap load)
- **Blocking probability** pK (Erlang-type finite formula)
- **Effective arrival rate** λeff = λ(1 − pK); Little's law uses λeff
- As K → ∞, converges to infinite-queue model

```python
import math

def mmn_finite(lam, mu, n, K):
    a = lam / mu
    rho = a / n
    p = [1.0]
    for k in range(1, K + 1):
        mu_k = min(k, n) * mu
        p.append(p[-1] * lam / mu_k)
    norm = sum(p)
    probs = [x / norm for x in p]
    pK = probs[K]
    lam_eff = lam * (1 - pK)
    L = sum(k * probs[k] for k in range(K + 1))
    Lq = sum(max(0, k - n) * probs[k] for k in range(K + 1))
    W = L / lam_eff
    Wq = Lq / lam_eff
    return dict(pK=pK, lam_eff=lam_eff, L=L, Lq=Lq, W=W, Wq=Wq)

print(mmn_finite(lam=10, mu=6, n=2, K=5))
```

## Week 8: M/M/n System with Losses

Pure loss system M/M/n/n: no waiting room, blocked arrivals lost. Dimensioned by **Erlang B** formula. Classic: telephone trunks.

### Erlang B

```
B(n, a) = (a^n / n!) / Σ_{k=0}^{n} (a^k / k!),   a = λ/μ
```

- Carried load = a(1 − B); utilization per server = a(1−B)/n
- Recursive computation avoids factorial overflow

```python
import math

def erlang_b(n, a):
    # iterative (stable) version
    B = 1.0
    for k in range(1, n + 1):
        B = (a * B) / (k + a * B)
    return B

a = 4.0  # Erlangs
for n in range(2, 8):
    print(n, round(erlang_b(n, a), 4))
```

## Week 9: Closed System

Finite population of M customers circulates (machine repair model): a failed machine joins the repair queue; repaired machines return to population.

### Machine Repair Model M/M/n/M/M

- Population M, each working machine fails at rate λ; repair rate μ per repairman
- Arrival rate depends on state: λk = (M−k)λ
- Throughput = λeff = mean failure rate = mean repair completion rate
- Key metrics: mean down machines L, availability, repairman utilization

```python
import math

def machine_repair(M, lam, mu, n=1):
    # lam: failure rate per machine, mu: repair rate
    p = [1.0]
    for k in range(1, M + 1):
        arr = (M - k + 1) * lam
        srv = min(k, n) * mu
        p.append(p[-1] * arr / srv)
    norm = sum(p)
    probs = [x / norm for x in p]
    L = sum(k * probs[k] for k in range(M + 1))
    lam_eff = sum((M - k) * lam * probs[k] for k in range(M + 1))
    W = L / lam_eff
    return dict(L=L, throughput=lam_eff, W=W, p0=probs[0])

print(machine_repair(M=5, lam=0.5, mu=2.0, n=1))
```

## Week 10: M/D/1 System

Poisson arrivals, **deterministic** service time (constant 1/μ). Less variability → shorter queues than M/M/1. Special case of M/G/1.

### Formulas

- ρ = λ/μ < 1
- Lq = ρ² / (2(1−ρ)); Wq = Lq/λ; W = Wq + 1/μ; L = λW
- Exactly **half** the M/M/1 queue (variance term vanishes)

| System | Lq |
|--------|-----|
| M/M/1 | ρ²/(1−ρ) |
| M/D/1 | ρ²/(2(1−ρ)) <span class="badge">½ of M/M/1</span> |

```python
def md1(lam, mu):
    rho = lam / mu
    assert rho < 1
    Lq = rho**2 / (2 * (1 - rho))
    Wq = Lq / lam
    W = Wq + 1 / mu
    return dict(rho=rho, Lq=Lq, Wq=Wq, W=W, L=lam * W)

print("M/D/1:", md1(8, 10))

def mm1_Lq(lam, mu):
    rho = lam / mu
    return rho**2 / (1 - rho)

print("M/M/1 Lq:", mm1_Lq(8, 10))
```

## Week 11: M/G/1 System

Poisson arrivals, **general** service distribution (mean E[S] = 1/μ, variance Var[S]). **Pollaczek-Khintchine** formula shows variance hurts.

### Pollaczek-Khintchine

```
ρ = λ·E[S]
Lq = λ²·E[S²] / (2(1−ρ))     where E[S²] = Var[S] + E[S]²
Wq = Lq / λ ;  W = Wq + E[S]
```

- Higher service variance → longer queues even at same ρ. <span class="badge warn">Variance matters</span>
- M/M/1 and M/D/1 are special cases (E[S²] = 2/μ² and 1/μ²)

```python
def mg1(lam, E_S, E_S2):
    rho = lam * E_S
    assert rho < 1
    Lq = (lam**2 * E_S2) / (2 * (1 - rho))
    Wq = Lq / lam
    return dict(rho=rho, Lq=Lq, Wq=Wq, W=Wq + E_S)

# M/M/1 as M/G/1: E[S]=1/mu, E[S^2]=2/mu^2
print("M/M/1 via PK:", mg1(8, 0.1, 2/100))
# M/D/1 as M/G/1: E[S^2]=E[S]^2
print("M/D/1 via PK:", mg1(8, 0.1, 0.01))
```

## Week 12: M/Ek/1 System

Erlang-k service: k exponential stages in series, each rate kμ. Bridges D (k→∞) and M (k=1). Models multi-phase service (check-in + scan + pack).

### Formulas

- E[S] = 1/μ, Var[S] = 1/(kμ²), E[S²] = (k+1)/(kμ²)
- Via P-K: Lq = ρ²(k+1) / (2k(1−ρ))
- k=1 → M/M/1; k→∞ → M/D/1

```python
def mek1(lam, mu, k):
    rho = lam / mu
    assert rho < 1
    Lq = (rho**2 * (k + 1)) / (2 * k * (1 - rho))
    return dict(rho=rho, Lq=Lq, Wq=Lq / lam)

for k in (1, 2, 4, 10):
    print(f"k={k}:", mek1(8, 10, k))
```

## Code Review Guide

### What to Look For

#### 1. Correctness
- Arrival/service distributions match the model?
- λ, μ in identical time units?
- Erlang B/C implemented with stable iteration?

#### 2. Stability & Edge Cases
- ρ ≥ 1 handled (error or finite-capacity fallback)?
- Division by (1−ρ) guarded?

#### 3. Simulation Quality
- Enough replications? Warm-up period discarded? Seed fixed?
